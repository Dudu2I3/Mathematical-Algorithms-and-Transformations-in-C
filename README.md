# Проект математических алгоритмов

Этот проект включает в себя несколько программ, решающих задачи на основе математических алгоритмов:

1. **Нахождение наибольшего простого делителя**:  
   Программа определяет наибольший простой делитель заданного числа с использованием вычитания вместо деления.

2. **Кодирование и декодирование строк с использованием ASCII**:  
   Программа выполняет операции кодирования и декодирования символов, принимая на вход команду и строки, разделенные пробелом.

3. **Рекурсивное вычисление чисел Фибоначчи**:  
   Программа находит n-е число Фибоначчи с помощью рекурсии.

4. **Расчет математических функций**:  
   Программа строит таблицу значений для функций Верзьера Аньези, Лемниската Бернулли и квадратичной гиперболы на заданном интервале.

В ходе выполнения этих заданий освоены основы работы с числами, строками, рекурсией и выводом данных в языке C.
